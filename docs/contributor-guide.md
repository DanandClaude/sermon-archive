# Your first tape: a guide for contributors

You upload a tape side, check what the app wrote about it, and approve it. Each side of a tape is its own
sermon, usually from a different Sunday.

## 1. Sign in

An admin adds you, and you get an email with a sign-in link. Open it and press **Sign in**. Later, go to the
archive's address and enter your email to get a new link. There's no password.

## 2. Upload

1. Choose **Upload tapes** on the left.
2. Drag the recordings onto the page, or use **Choose files**. You can add several at once, one file per side.
3. Under each file, type what the tape label says: **Date on label** and **Scripture on label**. Leave a box
   empty if the label doesn't say. **Speaker** and **Box or batch** are optional.
4. Press **Upload**. You can keep working while it goes, and if the connection drops, adding the same file
   again picks up where it stopped.

The **Processing queue** then shows each one being cleaned up, transcribed and summarized. This takes a while
for a long sermon. You don't need to keep the page open.

## 3. Review

When a sermon is ready, it appears under **Needs review**. Open it and check:

- **Title, date and speaker.** Fix anything that's wrong. What the label says counts over what the app
  guessed.
- **Summary.** Edit it freely, or ask for a new one.
- **Scripture.** Only passages the pastor reads or names out loud belong here. Press a passage to hear that
  moment. Use **Add passage** for one that's missing, edit a wrong one, or delete one he didn't name. Mark the
  sermon's text as **Main text**.
- **Transcript.** Open it to read along. Words the transcriber wasn't sure of are underlined. To fix a
  misheard word, choose **Edit** on its line, correct it and press **Save**.

**Save draft** keeps your changes without approving.

**If the recording is incomplete or the wrong tape,** press **Reject recording** and say what's wrong (for
example, "stops partway through the sermon"). The file is kept, not deleted, and everything you've entered
stays. The sermon then shows **Needs full recording**: open it, choose **Choose the full recording**, and press
**Upload**. It's processed again from the start and comes back to **Needs review**. An admin can do this for
any sermon.

## 4. Approve

Press **Approve & file**. The button tells you if anything required is missing, which is the date, the main
passage and a title. Once approved, the sermon gets its file name (such as
`1988-03-13_Hebrews-13-17_Submitting-to-Leaders`) and is copied to the church's archive drive. After that,
only an admin can change it.

## If something goes wrong

- **"Needs attention" on a sermon:** open it. The message says what happened, and **Retry** is on the page.
- **"Processing is paused":** the processing computer is off. Tell an admin. Your uploads are safe and wait
  for it.
- **A page says "Something went wrong":** press **Try again**. If it keeps happening, send an admin the
  reference shown on the page.
